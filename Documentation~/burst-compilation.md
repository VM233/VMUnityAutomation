# Native Burst recompilation after a managed rebuild

An explicit `asset/refresh` request may set `recompileBurst:true`. The existing durable workspace job first completes its normal C# compilation and assembly reload, then invalidates and recompiles Unity's integrated Burst assembly cache and waits for the native compiler's completion. This option requires Unity 6000.6 or newer and an enabled integrated Burst compiler. Omission preserves the existing C#-only contract. It changes neither Burst options nor project assets and does not reopen any Editor window.

The observed failure was a successful managed job following an earlier failed dependent-assembly compile. Scheduled voxel jobs still executed a native DLL older than the changed job layout: the first palette bytes were interpreted as a NativeArray length, and all tree raster outputs were empty. C# diagnostics, reload and source/IL inspection cannot prove native adoption. The repair uses the native compiler's own domain invalidation and recompilation APIs, with one original job identity. It never changes a job name, rearranges fields to fit stale code, disables Burst, or substitutes managed execution.

The workspace job owns one native request timestamp, its assembly-domain revision and a completion timestamp. It publishes the request before invoking the native owner, observes completion without reissuing, and fails if a new domain reload interrupts the native phase. A 600-second deadline bounds observation; timeout is a terminal failure, not a retry. Native completion is reported separately from C# error counts. Actual scheduled-kernel regressions remain required for behavior and native adoption acceptance.

Static Cost Ledger before executable writes: three exact reflected native methods resolved once per domain; one empty assembly-change list and one native whole-cache invalidation/recompile request per opted-in refresh; one native completion query per existing workspace update for at most 600 seconds. No new asset scan, timer, thread, transport, source enumeration, binary copying or cache directory deletion. Persisted timestamps/revision and response fields remain below 1 KiB. Compilation work belongs to Unity's existing native compiler and its registered assembly/entry-point set; this wrapper introduces no additional Cartesian loop or native compilation retry.
